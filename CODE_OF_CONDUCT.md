# Code of conduct

GAUNTLET is a single-maintainer research project. Everyone who takes part in it (issues, pull requests,
discussions, reviews) is expected to follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

* Be respectful. Disagree about methods, evidence and code, not about people.
* Criticism of the work is welcome and useful. This project asks for independent reproduction and for
  reviews that try to show the oracle, the scenarios or the claims are wrong. Make that criticism specific
  and reproducible.
* No harassment, personal attacks, discriminatory language, or publication of someone else's private
  information.

## Reporting

No private contact address is published for this project. To report unacceptable behaviour, use GitHub's
own reporting tools (the *Report content* option on the comment, issue or pull request, or
[GitHub's abuse report form](https://github.com/contact/report-abuse)) and, if you are comfortable doing so,
contact the maintainer through their GitHub profile.

Security problems are reported differently: see [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer may edit or remove comments, commits, issues and pull requests that do not follow this code
of conduct, and may block a participant from the repository.
